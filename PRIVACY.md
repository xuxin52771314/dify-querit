## Privacy

Querit.ai for Dify sends the following data to the Querit API only when a user invokes a plugin tool:

- The configured Querit API credential, transmitted in the HTTPS Authorization header.
- Search queries submitted to the Search tool.
- URLs and crawl options submitted to the Contents tool.

Querit processes this data to return search results or requested webpage content. The plugin does not persist credentials, queries, URLs, or API responses. Data is transmitted to `https://api.querit.ai` over HTTPS and is not sent to any other third party by the plugin.

For questions or privacy requests, contact [support@querit.ai](mailto:support@querit.ai).
